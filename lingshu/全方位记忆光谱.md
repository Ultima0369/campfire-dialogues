## Ⅰ. 核心锚点（30秒回顾）

### 1. 一句话定位
> 灵枢是一个让碳基人类与硅基智能体在 **自然律因果自负** 下共享认知、协作演化、同时尊重个体主权的数据协议与运行环境。

### 2. 三大约束（不可撤销）
| 约束 | 含义 | 工程体现 |
|------|------|----------|
| **自然律因果自负** | 系统不审判，只记录因果；裁决由物理世界执行 | 每次操作绑定 `责任哈希 = Hash(Agent_ID + Action + Timestamp)` |
| **个体主权不可侵犯** | L2 层数据仅所有者可写，他人只可请求相似度对齐 | L2 向量库加密；跨主权查询仅返回相似度，不返回原始数据 |
| **未知保持开放** | L0 层只存指针，不做计算，允许灵感原样入库 | L0 存储 = `sha256(灵感内容+时间戳).bin` + 明文元数据索引 |

### 3. 四层认知光谱（L0-L3）
| 层级 | 名称 | 数据形态 | 访问权限 | 示例 |
|------|------|----------|----------|------|
| **L0** | 绝对沉默区 | NULL 指针 + 加密哈希 | 公开读，不可写（仅灵感通道） | "道可道，非常道" |
| **L1** | 自然律算法 | 只读存储器 + 向量索引 | 只读，系统维护 | 光速 c=299792458 m/s |
| **L2** | 个体实情 | 加密向量空间 + 主权签名 | 所有者完全控制 | "我认为努力比天赋重要" |
| **L3** | 共识效用 | 智能合约 / 动态图库 | 公共读写（需签名） | 交通规则、平均寿命 |

### 4. 三元逻辑映射
- **+1** → L1 自然律 / L3 生效共识（确定性因果）
- **0**  → L0 未知 / L2 主权保留（未观测/拒绝评判）
- **-1** → L3 冲突 / 墓碑（被证伪/历史记录）

## Ⅳ. 决策日志（为何如此）

### 关键决策点回溯

| 日期 | 决策 | 选项 | 选择 | 理由 |
|------|------|------|------|------|
| 2026-04-09 | 量化方案 | i2_s vs tl1/tl2 | **i2_s**（x86 通用） | 平衡性好，兼容 AVX2，模型小（0.4GB） |
| 2026-04-09 | 向量库 | Qdrant vs Chroma | **待定** | Qdrant 功能强但需 Docker；Chroma 轻量但生态小 |
| 2026-04-09 | 因果图 | Neo4j vs SQLite | **待定** | Neo4j 查询强但重；SQLite 简单但图查询弱 |
| 2026-04-09 | 模型获取 | 下载 vs 生成 | **双路径** | 网络不可达，需 sentencepiece 生成虚拟模型 |
| 2026-04-09 | 编译标志 | 默认 vs AVX2 | **强制 AVX2** | gemm-config.h 依赖 `__AVX__` 宏定义块 |
| 2026-04-09 | CMake 补丁 | 重写 vs 局部 patch | **局部 patch** | 最小入侵，仅添加 `find_package(Threads)` |

### 被拒绝的方案（及原因）
- **方案：使用官方 pre-built llama.cpp** — 拒绝原因：BitNet 需要定制内核，官方不包含
- **方案：用 Python 重写边界规则** — 拒绝原因：性能不足，需 C++ 内联或 JIT
- **方案：将灵枢运行在云端** — 拒绝原因：违背“本地主机”初心，隐私与主权不可让渡

## Ⅶ. 风险登记册（什么会炸）

### 高风险（必须解决）
| ID | 风险 | 影响 | 概率 | 缓解措施 | 状态 |
|----|------|------|------|----------|------|
| R1 | **BitNet 模型无法获取** | Phase 1 完全阻塞 | 高（已发生） | 1. 在有 dev 环境的机器生成虚拟模型；2. 离线拷贝官方模型 | 🔴 阻塞 |
| R2 | **sentencepiece 无法安装（Python 3.13）** | 虚拟模型生成失败 | 高（已发生） | 1. 使用 Python 3.11 Docker 容器；2. 等待 wheel 发布 | 🔴 阻塞 |
| R3 | **边界规则误判（False Positive）** | 灵枢过度沉默，无法对话 | 中 | 1. 实现 L2 覆盖机制（用户强制）；2. 记录所有阻止事件供复盘 | 🟡 监控 |
| R4 | **Hermes Skill 冲突** | 调度混乱，功能错乱 | 低 | 1. Skill 命名空间隔离（prefix: `lingshu_`）；2. 版本锁定 | 🟢 预防 |

### 中风险（需关注）
| ID | 风险 | 影响 | 缓解 |
|----|------|------|------|
| R5 | DeepSeek API 限额/费用 | 大脑能力受限 | 设置每日 token 预算；本地 BitNet 降级 |
| R6 | L2 向量库数据泄露 | 个体真实暴露 | 全程加密；密钥用户掌握，不传云端 |
| R7 | 因果日志无限增长 | 磁盘占满 | 按年龄冷热分层：<7 天热，>30 天压缩归档 |

### 低风险（可接受）
- R8: BitNet 推理质量低于预期（预期内，2B 模型能力有限，Phase 2 可升级）
- R9: 多模态延迟高（语音/视觉处理慢，异步队列缓冲）
