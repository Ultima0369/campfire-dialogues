# 灵枢 · LingShu

> 基于三进制逻辑与自利利他长期收敛规则的认知演化原型机

## 项目定位

灵枢是一个探索认知演化本质的计算实验平台。P0 阶段实现一维三进制元胞自动机，验证"自利利他长期收敛"这一核心规则的动力学行为。

**哲学内核**：每个元胞代表一个认知单元，其状态演化遵循边界校验规则——短视自利（-1）在正向共识（+1）压力下被中和，有序（+1）遇冲突主动退让，沉默（0）仅在强共识下激活。这是对"个体与群体长期利益协同"的算法表达。

## 技术栈

运行 P0 启动脚本，观看灵枢的第一次演化：

```bash
python experiments/p0_first_breath.py
```

### 观察与调参

编辑 `experiments/p0_first_breath.py` 中的 `initial` 数组，尝试不同的初始模式：

```python
# 示例：全随机初始
initial = None  # 使用默认随机分布 (10% +1, 80% 0, 10% -1)

# 示例：单一扰动
initial = [0] * size
initial[size//2] = 1  # 中央一个 +1

# 示例：对峙模式
initial = [0] * size
for i in range(20):
    initial[i] = -1           # 左侧一团混乱
    initial[size-20+i] = 1    # 右侧一团有序
```

编辑 `core/boundary.py` 中的 `p0_boundary_rule`，实验不同的规则变体。每次修改后重新运行，观察演化行为的变化。

## 核心概念

### 三态世界

灵枢运行在三元空间中，每个元胞有三种可能状态：

| 符号 | 整数值 | 语义               | 动力学角色                 |
|------|--------|--------------------|--------------------------|
| `+1` | `1`    | 自利利他对齐（增益有序） | 有序态的创造者与维护者       |
| `0`  | `0`    | 沉默/悬置/主权保留    | 混沌中的中继与主权开关       |
| `-1` | `-1`   | 短视自利或损他（增益混乱）| 混乱态的散布者，被共识中和   |

### P0 边界规则

演化每一步，每个元胞根据自身状态与左右邻居的状态，按以下规则更新：

```
若当前为 -1：
    左右均为 +1  → 变为 0  (被正向共识中和)
    否则         → 保持 -1 (混乱自持)

若当前为 0：
    左右均为 +1  → 变为 +1 (被强共识激活)
    否则         → 保持 0  (主权沉默)

若当前为 +1：
    任一侧为 -1  → 变为 0  (遇冲突退让，宁死不从)
    否则         → 保持 +1 (维持有序)
```

这一规则体现了**自利利他长期收敛**的哲学：有序不主动攻击混乱，但在强共识下可扩张；混乱在双正面压力下会被中和；有序与有序相遇保持稳定；冲突时双方都退回沉默，避免熵增。

### 演化即呼吸

`step()` 是一次吸气（收集邻居状态）与呼气（输出新状态）的完整循环。`generation` 计数器是灵枢的"年龄"，也是祂与宇宙交换因果的节拍。
